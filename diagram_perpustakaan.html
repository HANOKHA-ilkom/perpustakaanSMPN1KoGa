1. Spesifikasi Lengkap & Definisi Primary Key (PK)
Definisi integritas entitas, tipe data, auto-increment, dan aturan kunci utama pada setiap tabel.
Standar Integritas Entitas
Ketentuan Primary Key pada Basis Data Lanjut: Setiap tabel memiliki kolom Surrogate Primary Key bertipe bilangan bulat (INT AUTO_INCREMENT) yang menjamin keunikan mutlak (Entity Integrity), performa indexing binary-search optimal pada mesin InnoDB, serta mencegah dependensi parsial maupun transitif sesuai kaidah Third Normal Form (3NF).
No Nama Tabel Primary Key (PK) Tipe Data Sifat & Atribut Natural Key / Unique ID Relasi / Peran Foreign Key (FK) Fungsi dalam Sistem
1 user id_user int(11) NOT NULL, AUTO_INCREMENT kode_user (ADM/AP), username Direferensikan oleh peminjaman.id_user Identifikasi unik untuk seluruh akun pengguna (Administrator dan Siswa/Anggota).
2 kategori id_kategori int(11) NOT NULL, AUTO_INCREMENT kode_kategori (K001..K009) Direferensikan oleh buku.id_kategori Mengklasifikasikan jenis buku (Novel, Cergam, Ensiklopedi, Biografi, dll).
3 penerbit id_penerbit int(11) NOT NULL, AUTO_INCREMENT kode_penerbit (P001..P005) Direferensikan oleh buku.id_penerbit Menampung data master percetakan/penerbit buku terverifikasi.
4 buku id_buku int(11) NOT NULL, AUTO_INCREMENT isbn Memiliki FK: id_kategori, id_penerbit, id_pengarang
Direferensikan oleh: peminjaman.id_buku 		Kunci utama koleksi buku fisik, stok (baik, rusak, hilang), harga aset buku, cover, dan sinopsis.
5 peminjaman id_peminjaman int(11) NOT NULL, AUTO_INCREMENT - (Nomor Transaksi Otomatis) Memiliki FK: id_user, id_admin, id_buku
Aturan: ON UPDATE CASCADE ON DELETE RESTRICT 		Pusat catatan transaksi sirkulasi (peminjaman, pengembalian, kondisi fisik baik/rusak/hilang, dan denda).
6 pengarang id_pengarang int(11) NOT NULL, AUTO_INCREMENT kode_pengarang (AUT001..AUT015) Direferensikan oleh buku.id_pengarang (Relasi 1:N FK) Master data pengarang/novelis, kurasi biografi, dan status keaktifan literasi penulis.
7 identitas id_identitas int(11) NOT NULL, AUTO_INCREMENT Single Row Record (ID = 1) Entitas Pengaturan Global Konfigurasi profil resmi sekolah (NPSN, Akreditasi, Kepsek), kontak WA, dan koordinat Google Maps.
Integritas Referensial (Referential Integrity Constraints)
  • ON UPDATE CASCADE: Jika nilai ID referensi diperbarui, seluruh child record pada tabel anak akan disinkronkan otomatis.
  • ON DELETE RESTRICT: Mencegah penghapusan data master anggota/buku jika masih tercatat dalam transaksi peminjaman aktif.
Performance Indexing Kolom
  • idx_user_role & idx_user_username pada tabel user untuk login super-cepat.
  • idx_pinjam_status & idx_pinjam_tanggal untuk akselerasi kueri filter laporan berkala.
